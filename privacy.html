Tietosuojaseloste

Päivitetty: 19.11.2026

1. Sovellus

HomeLaps (Voutilainen-Alykoti) on yksityiseen kotikäyttöön tarkoitettu älykodin hallintasovellus.

2. Google-kalenteritiedot

Sovellus käyttää Google Calendar APIa käyttäjän hyväksymien kalenterien tapahtumien lukemiseen. Tietoja käytetään tapahtumien, päivämäärien ja kellonaikojen näyttämiseen ohjauspaneelissa.

3. Käyttöoikeudet

Google-kalenteriyhteys on vain luku -tilassa. Sovellus ei luo, muuta tai poista kalenteritapahtumia.

4. Tietojen säilytys ja suojaus

Kalenteritapahtumat käsitellään paikallisella HomeLaps-palvelinkoneella. OAuth-kirjautumistunnukset säilytetään paikallisesti käyttöoikeuksin suojattuina. Kalenteritietoja ei julkaista tällä verkkosivulla.

5. Tietojen luovuttaminen

Kalenteritietoja ei myydä, käytetä mainontaan eikä luovuteta ulkopuolisille mainostajille.

6. Käyttöoikeuden peruuttaminen

Käyttäjä voi peruuttaa Google-käyttöoikeuden Google-tilinsä asetuksista: Google Account Connections. Paikalliset kirjautumistunnukset voidaan poistaa HomeLaps-palvelinkoneelta.

Privacy Policy

Last updated: November 19, 2026

1. Application

HomeLaps (Voutilainen-Alykoti) is a private smart home dashboard for personal household use.

2. Google User Data

HomeLaps uses the Google Calendar API to read authorized calendar events and display event titles, dates and times on the local dashboard.

3. Permissions

Calendar access is read-only. HomeLaps does not create, modify or delete Google Calendar events.

4. Data Storage and Security

Calendar data is processed on the local HomeLaps server. OAuth credentials are stored locally with restricted file permissions. Calendar data is not published on this website.

5. Data Sharing

Google user data is not sold, used for advertising or disclosed to advertisers.

6. Revocation and Deletion

Users can revoke access through their Google Account settings. Locally stored OAuth credentials can be deleted from the HomeLaps server.

7. Google API Services User Data Policy

HomeLaps' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
